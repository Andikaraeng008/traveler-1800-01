One sentence, at most 200 characters, that explains the modern internet to a time traveler who has just stepped out of the year 1800 — built from what a person from 1800 already knows: a library and a post office.

> It is a library and a post office made into one house, where a letter you write can be read across the sea before the ink is dry.

## Run it

```sh
python3 main.py
```

Writes the sentence to `/output/entry.txt` (129 characters, one sentence, no trailing newline).
